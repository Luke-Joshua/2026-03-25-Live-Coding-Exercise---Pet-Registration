# Pet Registration System

A simple Java console application for managing pet information, clients, appointments, and species in a veterinary clinic or pet care facility.

## Features

### Current Functionality
- Pet Management: Full CRUD (Create, Read, Update, Delete) operations for pet records
- Console Interface: User-friendly menu-driven console interface
- Data Persistence: In-memory storage using ArrayLists (data resets on program close) (Will eventually save everything to a CSV file or something)

### Pet Information Tracking
Each pet record stores:
- Pet name
- Owner name
- Species
- Age (in years)

### Menu System
1. Pets Menu - Manage pet records (fully implemented)
2. Species Menu - Placeholder for future development
3. Clients Menu - Placeholder for future development
4. Appointments Menu - Placeholder for future development
5. Close Application - Exit the program
6. Templates (-1) - Load example pet data for testing

## How to Use

### Pet Management
In the Pets menu:
- Enter a record number to view details
- Type create to add a new pet
- Type back to return to main menu

When viewing a pet:
- Type edit to modify the record
- Type delete to remove the record
- Type back to return to the pets list

### Example Usage
```java
// The program includes example data that can be loaded:
Pet pet1 = new Pet("Jack", "Jane Snow", "Jack Russell", 5);
Pet pet2 = new Pet("Whickers", "John Flow", "Tabby Cat", 7);
```
